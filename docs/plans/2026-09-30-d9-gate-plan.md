# D9: one gate definition (`make gate` and `make test-integration`)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans with superpowers:test-driven-development. Every task starts with a failing test.

**Goal:** Two Makefile targets are the only test entry points. `make gate` runs lint, then build, then the unit tier, and it is the command that CI, `gt done` and the future land path run. `make test-integration` runs the post-merge tier, including every Docker-backed package.

**Decision:** wayfinder D9 item 3 (claude-1ey.9, epic gt-ik4a1). Out of scope: removing the `-run '^TestIntegration'` filter (gt-ik4a1.2), moving the live-town tripwire to doctor (item 5), and deleting the container gate's unwrapped-container hold and `reserved_for_gate` (the gt-ik4a1.1 notes: that waits for the beads unit tier).

## The contract

| target | runs | Docker | exit |
|---|---|---|---|
| `make gate` | `make lint`, then `go build ./...`, then the unit tier: the budget runner over `./...` beside `test-makefile` | never: the recipe sets `GT_TEST_DOCKER=0` itself, so an inherited value cannot turn containers on | 0 green; any non-zero red (make reports a failed recipe as 2). The last `gate:` line names the failed stage for humans only. |
| `make test-integration` | `-tags integration -run '^TestIntegration' ./...`, then the whole of each package in `internal/testpolicy/docker.txt` | yes: the recipe sets `GT_TEST_DOCKER=1`; the caller wraps it in `gt slot run` | 0 green; non-zero red |

Deleted: `test`, `test-changed` and `PKGS`, the `GT_TEST_DOCKER=$${GT_TEST_DOCKER:-1}` opt-in defaults, every `-timeout 20m` (go test's 10 m per-package default applies), CI's raw `go test -race -short` job and its separate lint job, and CI's per-push integration job (the nightly workflow keeps running the integration tier daily). Kept, as they are not gates: `test-makefile` (a stage of the unit tier), `test-timing` (a measurement) and `test-e2e-container` (the e2e workflow).
