# D4 core: intent record, one liveness function, supervisor verbs — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans with superpowers:test-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking. Every task starts with a failing test.

**Goal:** Every automated kill or restart of a town seat in the daemon, witness, tmux, session and doctor packages goes through one `Kill` or `Restart` that enforces pause, e-stop, a persisted 3-per-hour budget and actor logging, and decides from one fail-closed intent file per seat and one liveness function.

**Architecture:** Three new packages. `internal/intent` owns the per-seat file `<town>/.runtime/agents/<rig>/<role>[.<name>].json` (the path the pause marker already uses; the pause marker becomes a view of the intent record). `internal/liveness` returns `Alive | Dead | Stalled | Unknown` from tmux, the pane process tree and a progress sample persisted in the intent record. `internal/supervisor` holds `Kill`, `Restart` and `KillStray`; the daemon owns the long-lived instance, and the two CLI hosts that still act before their sibling tickets land (the witness `gt patrol scan`, `gt doctor --fix`) build one with the same file-based guards.

**Tech Stack:** Go, tmux, gofrs/flock, `internal/atomicfile`, bd CLI only for the agent-bead display mirror.

**Spec:** `docs/adr/0003-one-supervisor-no-idle-llm.md`; epic gt-4k3fj (items 1, 2, 7, 8 and DELETES); tickets gt-4k3fj.1/.2/.3; `~/.claude/docs/research/deep-review/gastown-control-plane.md` G1-01..G1-20 and "Refactor candidates"; `patrol-steps-vs-daemon.md`. Builds on `2026-09-29-w2-liveness-plan.md` (checked liveness, no `IsAgentAlive`), `2026-09-29-w2-failclosed-plan.md` (`bdgate.Require` in daemon restarts), `2026-09-29-w2-client-plan.md` (bd verbs, no library).

## Global Constraints

- Intent file path is exactly `agentpause.FilePath(town, rig, role, name)`. It always serializes `"paused": <bool>`: the stuck-agent-dog shell reads `.paused` and fails closed on `null`.
- Intent reads never touch Dolt. A file that exists but cannot be read or parsed reads as held (parked + frozen) plus an error.
- Writes are atomic (temp + rename) under an flock at `<town>/.runtime/locks/intent/<rig>/<stem>.lock`, so the agents directory holds only marker files.
- Restart budget: 3 restarts per seat per rolling hour, persisted in the intent file. The fourth is refused, the seat is frozen, and one line goes to the operator.
- `Kill` and `Restart` are refused while the seat is paused or frozen, and while the town or the seat's rig is e-stopped (read fail-closed). `Restart` is also refused during shutdown (`shutdown.lock`).
- Unknown is never acted on. Progress is measured by change (pane hash, transcript mtime/size, heartbeat cycle), never by elapsed turn time.
- Agent beads are display mirrors, written best-effort through bd (`ForAgentBead().UpdateAgentState`) after the file; no decision reads them.
- Stay inside internal/daemon, witness, tmux, session, doctor and the new packages. Wiring outside (deacon, mayor managers for the respawn-hook delete; cmd for `clear-backoff`) is minimal and in its own commit.
- No AI attribution anywhere.

## Decisions recorded

- The verbs live in `internal/supervisor`, not `internal/daemon`: the daemon imports the witness, so a daemon-resident function could not be called by the witness scan that still restarts polecats until .6. The guards are file-based, so every host enforces the same rules; the daemon owns the long-lived instance.
- The intent record reuses the pause marker path and fields. One file per seat, one reader contract, and the shell dog keeps working.
- A budget-exhausted seat is written as paused (`paused_by: supervisor`), so `gt status`, `gt agent resume` and every existing pause reader see it with no new surface.
- `desired=stop` is written by Kill and `run` by Restart; nothing refuses on `stop` yet, because sling does not write `run` until the dispatcher (.5).
- E-stop refuses Kill as well as Restart: "running sessions finish" means no automated kill either. kill-all (.4) will bypass it explicitly.

## Execution notes

- **Declined restarts.** A role manager that starts nothing on purpose
  (fork-backed rig, refinery safety stop, a session someone else already
  raised) returns an error wrapping `supervisor.ErrDeclined`; the attempt is
  logged as `declined` and gives its budget stamp back. Without it a
  fork-backed rig's refinery would freeze itself within an hour.
- **Dead panes.** With the respawn hook gone, a pane kept after its process
  exited (remain-on-exit from an older session, a handoff, a quota rotation)
  would read Unknown forever: the process query has no command to answer
  with. tmux gains a checked `PaneDead`, and `liveness.Assess` calls such a
  seat Dead. `IsAgentAliveChecked` stays error-preserving (the fail-open
  guard lint rejected swallowing the error there). The deacon no longer sets
  remain-on-exit, which only served the hook.
- **Debounces are persisted.** The deacon's two-tick stall debounce is the
  liveness baseline (a first sample never yields a verdict); the mayor's
  three-cycle zombie debounce is `progress.dead_samples` in its intent
  record. Both survive daemon restarts.
- **Crash check without agent beads.** The daemon's done/nuked and spawning
  guards read agent-bead fields. They are replaced by the work bead: finished
  work is closed and so not listed; the spawn grace is the hooked work bead's
  `updated_at` (5 minutes). The crash itself is still a finding (the
  CRASHED_POLECAT mail); restarting crashed polecats from the daemon is the
  witness tick's job (.6).
- **Budget exhaustion is a pause.** A frozen seat is written as paused by
  `supervisor` with the budget reason, so `gt status` shows it and
  `gt agent resume` frees it (and empties its budget).
  `gt daemon clear-backoff <agent>` clears the freeze and the budget too; its
  SIGUSR2 to the daemon is now a logged no-op. The old gt-ayx auto-clear of a
  stale crash-loop flag is gone by design: epic item 8 parks the seat and
  tells the operator.
- **Witness and doctor hosts** build a supervisor per call with no bead
  mirror; only the daemon mirrors holds onto agent beads, and only when it
  has a resolved bd.
- **SIGUSR1** used to trigger the deleted lifecycle intake. It is still
  caught (its default action would end the daemon) and logged as ignored.
- Left as dead config for the kernel (gt-y3pgh.1, D5): the
  `max_lifecycle_message_age` operational key. The daemon.json
  `patrols.restart_tracker` block is removed; decoding ignores unknown keys,
  and the live town's daemon.json does not set it.
- Pre-existing, not touched: gofmt drift in `internal/daemon/types.go`,
  `town_config_test.go` and `internal/doctor/claude_settings_check.go`;
  `go vet -tags integration ./internal/daemon/` fails on origin/main in
  `convoy_manager_integration_test.go` (`m.seeded`).
- Not converted, and why: `ensureBootRunning` spawns Boot per triage run, so
  budgeting it as a restart would freeze Boot within an hour (Boot moves to a
  daemon job under .6); `cleanupOrphanedProcesses` and
  `KillOrphanedDaemons` kill processes, not seats (.9 owns process identity).
